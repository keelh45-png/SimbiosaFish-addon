# SimbiosaFish — starter project

This is a starter plugin scaffold, not a finished fishing add-on.

Currently implemented:
- Plugin entry point that logs when enabled.

Not implemented yet:
- Per-rod catch quotas (Basic 50, Iron 75, Diamond 100, Emerald 150, Mythic 200)
- Persistent quota lore and rod removal at zero
- EvenMoreFish bait validation/integration
- Preventing durability loss on custom rods

Compatibility:
- Build baseline uses Paper API 1.21.4 and Java 21.
- This has not been verified against Paper 26.2.
- Do not install the JAR on a production server until tested.
